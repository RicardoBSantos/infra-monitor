PARTE A --- DISPONIBILIDADE POR UNIDADE

5. Objetivo

Implementar agregação temporal por Unidade sem usar média simples dos
percentuais.

A fórmula oficial é:

tempoMonitoradoUnidade =
Σ tempoMonitorado dos Monitores CALCULADO

tempoIndisponivelUnidade =
Σ tempoIndisponivel dos Monitores CALCULADO

tempoDisponivelUnidade =
tempoMonitoradoUnidade - tempoIndisponivelUnidade

disponibilidadePercentual =
round(
tempoDisponivelUnidade
/ tempoMonitoradoUnidade
* 100,
  2,
  HALF_UP
  )

Se:

tempoMonitoradoUnidade = 0

então:

disponibilidadePercentual = null

Proibido:

AVG(percentual dos Monitores)

6. Contagens por Unidade

Implementar:

equipamentosTotal
equipamentosMonitorados
equipamentosSemMonitoramento
equipamentosSemDados
incidentes

Regras:

equipamentosTotal

Quantidade distinta de Equipamentos da Unidade que entram no universo
analítico do filtro/período.

equipamentosMonitorados

Quantidade distinta de Equipamentos que possuem ao menos um Monitor ICMP
com resultado CALCULADO.

equipamentosSemMonitoramento

Quantidade distinta de Equipamentos cujo resultado analítico é
SEM_MONITORAMENTO.

equipamentosSemDados

Quantidade distinta de Equipamentos que possuem Monitor ICMP, mas nenhum
Monitor calculável no período e ao menos um resultado SEM_DADOS.

incidentes

Quantidade de Incidentes distintos que efetivamente intersectaram tempo
monitorado dos Monitores considerados.

Não duplicar Incidente por JOIN.

7. Equipamento com múltiplos Monitores

Um Equipamento com dois Monitores:

conta 1 vez em equipamentosTotal

Se ao menos um Monitor for CALCULADO:

conta 1 vez em equipamentosMonitorados

Os tempos, entretanto, somam os resultados de todos os Monitores
CALCULADO.

8. Qualidade da Unidade

Se o DTO de Unidade expuser qualidade:

PRECISA
INFERIDA

a regra conservadora é:

qualquer contribuição INFERIDA
→ qualidade Unidade = INFERIDA

Se reports-architecture.md não definiu qualidade para Unidade, não
inventar campo público.

11. Cenário U2 --- provar média ponderada

Criar:

tempoIndisponivel = 0

tempoIndisponivel = 3240

resultado != 95.00

17. Semântica temporal

Selecionar Incidentes que intersectam o período:

iniciadoEm < fim
AND
(encerradoEm IS NULL OR encerradoEm >= inicio)

ou equivalente coerente com [inicio,fim).

18. Duração no período

Calcular:

inicioEfetivo = max(iniciadoEm, inicioRelatorio)

fimEfetivo = min(
encerradoEm ?? fimRelatorio,
fimRelatorio
)

Então:

duracaoSegundosNoPeriodo =
max(0, fimEfetivo - inicioEfetivo)

Não retornar duração total fora do recorte.
