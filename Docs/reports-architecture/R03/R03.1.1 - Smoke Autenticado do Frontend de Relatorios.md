R03.1.1 --- Smoke Autenticado do Frontend de Relatórios --- Infra Monitor

1. Objetivo

Eliminar a única ressalva restante da R03.1 por meio de smoke tests
autenticados contra o backend real.

A R03.1 já entregou:

rota /relatorios;

lazy loading;

sidebar;

RBAC para ADMIN, OPERADOR e VISUALIZADOR;

seis DTOs tipados;

PageResponse<T>;

RelatorioApiService;

filtros tipados;

serialização correta de HttpParams;

87 testes frontend;

build aprovado sem warning de budget.

A R03.1.1 deve apenas validar que o frontend consome corretamente o
contrato real do backend.

2. Escopo

Validar:

frontend Angular real
+
backend Spring Boot real
+
PostgreSQL isolado
+
autenticação JWT

Não implementar novas telas analíticas.

Não iniciar R03.2.

3. Pré-condições

Considerar homologado:

R02 — backend de Relatórios
R03.1 — implementação frontend com ressalva apenas de smoke
