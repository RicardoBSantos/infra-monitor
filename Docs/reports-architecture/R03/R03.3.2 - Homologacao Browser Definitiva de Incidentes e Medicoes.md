2. Regra central desta fase

3. Regra obrigatória de browser

Usar:

Chrome/Chromium
+
Playwright

ou automação equivalente capaz de observar:

navegação;

headers;

status;

console;

viewport;

overflow;

interações nativas.

Se Chrome/Playwright não estiver imediatamente disponível:

localizar instalação existente;

verificar dependências do projeto;

usar browser já instalado;

configurar execução headless quando apropriado;

tentar executar a automação;

somente registrar bloqueio se houver impedimento técnico real.

É proibido simplesmente marcar toda a matriz como pendente sem tentar
executar a automação.

4. Regra obrigatória de ambiente

Antes dos testes, garantir:

Backend:

http://localhost:8080

Frontend:

http://127.0.0.1:4200

Se não responderem:

verificar portas;

encerrar processos antigos/desatualizados;

subir PostgreSQL isolado;

subir backend atualizado em 8080;

aguardar /actuator/health = 200;

subir frontend atualizado em 4200;

aguardar frontend = 200;

somente então iniciar browser.

Não encerrar a fase alegando indisponibilidade sem antes tentar subir os
serviços.

5. Antes de qualquer alteração

Executar:

git status
git diff

Por padrão:

não alterar produção

Só corrigir código se bug real for reproduzido no browser.
