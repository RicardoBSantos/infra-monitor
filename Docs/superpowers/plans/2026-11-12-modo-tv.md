# Modo TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modo TV em `/tv` que gira Mapa → Painel → Incidentes → Relatórios e rebusca dados em silêncio, configurado pelo admin numa tela de Configurações persistida na V27.

**Architecture:** Backend: módulo `configuracao` com JDBC tolerante (sem JPA) sobre V27, GET para todos os papéis e PUT ADMIN com semântica "ausente preserva"; correção do plano genérico nas consultas de latência. Frontend: cada uma das 4 telas ganha `recarregarDados()` silencioso; `TvComponent` fora do shell mantém as telas montadas e alterna visibilidade; página `/configuracoes/modo-tv`.

**Tech Stack:** Java 21, Spring Boot 4.1, JdbcTemplate, Flyway, Testcontainers (`@RequerDocker`); Angular (signals, standalone, OnPush), Vitest, Playwright (`e2e/*.cjs`), MapLibre.

**Spec:** `Docs/superpowers/specs/2026-11-12-modo-tv-design.md`
